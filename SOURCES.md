## Vietnamese translations (NOT bundled)
Vietnamese translations by Hòa thượng Thích Minh Châu are **not redistributed** in this repository, because no explicit open license for them was found. When online, the app loads them live from the SuttaCentral API for reading only, with attribution and a link to the original page.

## Audio
No recordings are used. Bell and wooden-fish sounds are synthesised in the browser with the Web Audio API.

## Lunar calendar
Implemented from the published astronomical algorithm of Hồ Ngọc Đức (Vietnamese lunar calendar, UTC+7).
